# Job-Board-Bootstrap_Based
Career Board Pro (Bootstrap Based)
A modern, responsive Job Board UI built using HTML and Tailwind CSS.
This project demonstrates a full-featured front-end job portal with job listings, filters, authentication modals, and recruiter job posting functionality.

***UI Sections***
Sticky navigation bar
Hero section with job search UI
Available jobs grid
Job listings with sidebar filters
Popular jobs section
Footer with quick links
Multiple modals (Apply, Login, Post Job)

***Tech Stack***
HTML5
Tailwind CSS (via CDN)
Vanilla JavaScript
No backend (UI-focused project)
